Depth refinement for coordinator and art owners, effective before production art integration. `WorldArtModule` now optionally exports `renderObjects(map, view): WorldRenderObject[]`. Each object has a stable `id`, world `position`, optional explicit `depth` (default x+y), optional `occlusion`, and `draw(ctx, view)`. The single foundation compositor sorts these individual entries together with player/NPC actors. Use the corresponding map prop ID to override its generic fallback. Ground and foreground stay in `drawMap` passes. The legacy whole `objects` drawMap pass remains compatible as a background object layer, but tall buildings/props that overlap actors MUST use renderObjects. This fixes the inability to interleave actors inside one monolithic object pass. No owner needs to create a renderer or frame loop.

# Research fact-check — 31 October 2026

The main changes are:

- **Godot’s C# web restriction still applies; Phaser’s current release is 4.2.1.**
- **Several costs need correction:** Haiku cache reads, Gemini image pricing, OpenAI TTS billing units, Google’s free allowance, and hosting assumptions.
- **Revenue and conversion evidence is weaker than presented:** Duolingo’s subscriber ratio is not conversion; RevenueCat’s quoted percentages concern trials; the comparable-game sales remain estimates.
- **Policy claims need narrower wording:** Apple does not exempt native games from 4.2, and Steam’s public documentation does not substantiate every claimed coding-tool exemption.
- **Art-production budgets and model-quality rankings remain planning assumptions.**

No files were modified. Repeated claims are grouped within each note. **CONFIRMED** can mean a documented vendor claim or developer self-report; the note column identifies that limitation. Prices are USD unless otherwise stated. Cached storefront figures are not treated as exact, live counts.
